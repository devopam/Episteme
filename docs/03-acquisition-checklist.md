# Data Acquisition Checklist – Phase 0

## 1. Infrastructure
- [ ] 8 TB external SSD ready and formatted
- [ ] Clear folder structure created
- [ ] License tracking spreadsheet set up
- [ ] Download tools installed (aria2, rclone, AWS CLI, etc.)

## 2. Core Scientific Literature
- [ ] PubMed baseline + update mechanism
- [ ] PMC Open Access Subset – **Commercial Use Allowed only**
- [ ] Europe PMC Open Access Subset
- [ ] Snapshot dates and license filters documented

## 3. Multilingual Corpora
- [ ] MMedC (or available subsets)
- [ ] ApolloCorpora (all supported languages)
- [ ] Provenance and licenses recorded

## 4. Guidelines & Authoritative Sources
- [ ] Meditron / EPFL public guidelines subset
- [ ] WHO guidelines
- [ ] OpenWHO materials (where license permits)
- [ ] NICE, CMA and other redistributable collections
- [ ] SciELO / LILACS open content

## 5. Language-Specific Supplements
- [ ] Chinese open sources (via Apollo / MMedC first)
- [ ] Spanish / Portuguese (SciELO etc.)
- [ ] Other languages only from clearly open packaged sources

## 6. Supporting Data
- [ ] Public multilingual medical QA / exam datasets
- [ ] General-domain replay data
- [ ] Open textbooks (multiple languages)

## 7. Quality & Documentation
- [ ] Consistent quality filtering applied
- [ ] Deduplication completed
- [ ] Decontamination against evaluation benchmarks
- [ ] Living inventory maintained (source, language, tokens, license, date)
- [ ] Excluded sources log kept

## 8. Final Validation
- [ ] Spot-check samples from major languages
- [ ] Confirm no restricted content included

- [ ] Token distribution by language/region reviewed
